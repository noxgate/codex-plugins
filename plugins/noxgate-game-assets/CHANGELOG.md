# 更新记录

## 0.3.1

- 图片素材技能的显示名改为「Noxgate 图片素材」，调用名改为 `$noxgate-image-assets`。
- 图片素材支持当前 API Key 授权的图片生成模型，待选模型和费率随权限更新。
- 图片素材和游戏音频技能须由用户显式调用，继续复用已有的有效授权。

## 0.3.0

- 首次使用时可一次授权两个插件所用的权限，有效凭据可跨插件和会话复用。
- 批量清单缺少模型时，会先显示当前可用模型、基础费率及可计算的预估费用，等待用户选择。
- 增加按平台分发的安装包，内含 Python 和该插件所需的依赖。
- 统一各工具的启动入口，由启动器选择运行环境。

## 0.2.2

- 将游戏音频示例模型更新为当前 NoxGate 可用 ID `doubao-seed-audio-1-0`。

## 0.2.1

- 修复网页授权批准或拒绝后，本机回调因 Origin 为 null 返回 403 的问题。
- 调整回调页 Referrer Policy，继续严格校验来源、state 和 PKCE，不新增授权步骤。
- 已安装 0.2.0 的用户需更新插件；若使用独立 CLI，还需重新运行更新后插件的安装器，再重新发起授权。

## 0.2.0

- 2026-11-15 修复审核发现的恢复回归：received 异步任务重查、同步媒体私有缓存、多文件写入失败恢复。
- 新增 noxgate tasks migrate-state，旧状态显式绑定 profile 并校验原网关和在线任务归属。
- auth ensure 的自建地址、Agent、存储和 scope 在首次授权及重授时均生效；授权通过本机浏览器回调完成。

- 默认使用 NoxGate 浏览器登录、选择 API Key 并签发独立可撤销插件凭据，不再读取 Codex provider 地址或密钥。
- 共享多 profile 认证运行时；默认跨平台私有文件存储，系统安全存储与便携 `.env` 均需用户显式选择。
- 随包提供 bin/noxgate 与 bin/install.py；显式 import-codex 只导入公开地址并重新授权，不复制密钥。
- 任务状态仅保存恢复元数据，不保存完整响应或签名 URL。
- WorkBuddy 仅提供通用 CLI 适配契约，尚未完成产品内实测。

## 0.1.1

- 多素材请求在建立清单前主动评估组合图，适合的同类素材、图标可分组同图生成，不适合的内容分别生成。
- 同步组合图参考说明，保留用户对独立生成及文件交付的要求。

## 0.1.0

- 首次发布 NoxGate 游戏资产插件。
- 包含 GPT Image 2.5 游戏图片批量生产、组合图拆分、逐帧图集组装和校验。
- 包含游戏音乐、战斗音乐、音效和环境音的批量音频生产流程。
- 统一读取当前 Codex provider 配置，不包含 API key、base URL 或具体项目资料。
